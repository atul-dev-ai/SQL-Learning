Welcome to the **SQL Mastery Repository**! This repository serves as a structured, comprehensive learning path for mastering SQL and relational database design. It is designed to take you from foundational database concepts to advanced query optimization and complex system architectures.

## 🎯 Objective
This repository is tailored to build the skills necessary for designing robust, scalable databases for real-world applications (such as Multi-Tenant Systems, ERPs like BrainCampus, and E-commerce platforms).

---

## 📂 Repository Structure

The curriculum is divided into 10 core modules, culminating in 3 real-world capstone projects. Each module contains theoretical explanations and practical SQL scripts.

```text
SQL-Learning/
├── 01-Basics/            # Intro to DBs, Tables, Primary & Foreign Keys
├── 02-Data-Types/        # Standard SQL & PostgreSQL specific data types
├── 03-DDL/               # CREATE, ALTER, DROP, TRUNCATE
├── 04-DML/               # INSERT, UPDATE, DELETE
├── 05-SELECT/            # Data retrieval, WHERE, ORDER BY, LIMIT
├── 06-Operators/         # Comparison, Logical, BETWEEN, IN, LIKE
├── 07-Functions/         # Aggregate (COUNT, SUM) & String Functions
├── 08-JOIN/              # INNER, LEFT, RIGHT, FULL, and SELF JOINs
├── 09-Relationships/     # 1:1, 1:N, M:N Architectures
├── 10-Advanced/          # Subqueries, CTEs, Window Functions, Views
└── projects/             # Capstone Projects
    ├── university-db/    # University/School Management System
    ├── ecommerce-db/     # E-Commerce Architecture
    └── school-erp-db/    # Comprehensive ERP Database
```

## 🗓️ Learning Roadmap

### 🔹 Module 1-2: Foundations & Data Types
Understand how data is stored, structured, and typed. Learn the building blocks of tables, constraints, and relationships.

### 🔹 Module 3-4: DDL & DML (CRUD Operations)
Master the ability to define database schemas and manipulate data.
- **DDL:** `CREATE`, `ALTER`, `DROP`
- **DML:** `INSERT`, `UPDATE`, `DELETE`

### 🔹 Module 5-7: Querying & Filtering Data
Extract exactly what you need from the database using powerful filtering and aggregation.
- **Key Concepts:** `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, Pattern Matching.

### 🔹 Module 8: The Power of JOINs
Learn to combine data from multiple tables efficiently. **This is critical for relational databases.**
- Understand the performance implications of different `JOIN` strategies.

### 🔹 Module 9: Database Relationships & Normalization
Design robust architectures.
- **1:1, 1:N, M:N** mapping.
- *Pro Tip:* Crucial for structuring multi-tenant platforms and complex ERPs.

### 🔹 Module 10: Advanced SQL
Take your skills to a professional level.
- **Common Table Expressions (CTEs) & Subqueries:** For complex, multi-step data retrieval.
- **Window Functions:** For advanced analytics (running totals, ranking).

### 🏆 Capstone Projects
Apply your knowledge by designing complete databases from scratch:
1. **University Database:** Students, courses, enrollments.
2. **E-Commerce Database:** Products, carts, orders, payments.
3. **School ERP Database:** A massive, scalable system tracking sessions, attendance, results, fees, and more.

## 🛠️ Getting Started

1. Clone this repository to your local machine.
2. Install your preferred SQL environment (PostgreSQL recommended).
3. Navigate through the folders sequentially, starting from `01-Basics/`.
4. Read the comments in each `.sql` file and execute the queries to see the results.

Happy Querying! 🎉
